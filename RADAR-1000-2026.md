## Les 8 critères qui font le prix

1. **Extension** : .com d'abord ; .ai seulement à mot fort ; .org qui revient ; ccTLD locaux à mot exact.
2. **Longueur** : ≤ 8 lettres ; 3-4 lettres = plancher liquide qui monte.
3. **Structure** : 1 vrai mot > tout ; 2 mots seulement si c'est LA catégorie (PrivateLLM.com 250 k$) ; acronymes liquides.
4. **Verticale** : IA/agents > fintech/paiements > santé > énergie > juridique > logistique.
5. **Acheteur identifiable** : le prix vient de startups financées qui achètent leur catégorie.
6. **Liquidité** : non listé (Afternic+Sedo+Atom) = invendable ; prix Buy Now obligatoire.
7. **Âge & historique** : expirés à backlinks propres = achat 1-500 $, revente au retail moyen (2 753 $).
8. **Timing** : acheter le vocabulaire AVANT la vague (agentic/MCP raflés en 2025 ; prochaines vagues : facture électronique FR, paiements d'agents, humanoïdes, PQC).

## Le modèle de scoring

`Score = base_extension × (longueur + structure + verticale + acheteur_B2B [+ âge/autorité pour les expirés])`
Barème complet dans le rapport web. Anti-spam Tier 1 : BL/RD ≤ 800, corroboration Majestic↔Semrush, TF > 0, exclusions marques/personnes.
